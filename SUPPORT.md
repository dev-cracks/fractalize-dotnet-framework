# Support

- **Questions and ideas:** open a
  [feature request](https://github.com/dev-cracks/fractalize-dotnet-framework/issues/new/choose) describing what you need.
- **Bugs:** open a [bug report](https://github.com/dev-cracks/fractalize-dotnet-framework/issues/new/choose) with steps
  to reproduce.
- **Security issues:** never in public; follow the [Security Policy](SECURITY.md).

This project is maintained on a best-effort basis; there is no guaranteed response time except for
security reports.
